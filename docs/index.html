RoomSync is a Spring Boot + MySQL web app for roommates: shared expenses, recurring bills, payments and balances.

This GitHub Pages site is a project overview. GitHub Pages can only host static files. The working app runs locally with Java and MySQL — it is not executed here.

What the app does

Roommates

Add the people who share the home and keep every bill with the right group.

Bill splitting

Equal or custom splits. Amounts are calculated in Spring Boot with BigDecimal.

Recurring bills

Rent, Wi-Fi and utilities can generate the next expense when they are due.

Payments

Record full or partial payments. This tracks money; it does not transfer it.

Balances

See who paid the original bill and who still owes their share.

Dashboard

Summary cards and a monthly chart load from MySQL, not hardcoded values.

Run it on your computer

You need Java 21+ and MySQL 8. From the project folder:

.\mvnw.cmd spring-boot:run

Then open http://localhost:8080. Set your MySQL password in a local application-local.properties file (not committed to GitHub).
